# Flag Guesser

## Running the App

Install dependencies:

```
npm install
```

Start the development server:

```
npm run dev
```

Build for production:

```
npm run build
```

Preview the production build:

```
npm run preview
```

## Generating PNGs

To generate PNGs run script `generate_pngs.py`:

```
uv run generate_pngs.py
```

To use a custom width run with optional height parameter:

```
uv run generate_pngs.py 1000
```
